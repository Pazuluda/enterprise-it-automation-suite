# Politique de sécurité

## Signalement d'une vulnérabilité

Ne publiez pas de vulnérabilité, secret ou preuve d'exploitation dans une issue GitHub publique.

Utilisez le signalement privé de vulnérabilité GitHub lorsqu'il est disponible. À défaut, contactez le mainteneur par un canal privé.

## Versions prises en charge

| Version | Statut |
|---|---|
| `v0.1.x` | Prise en charge actuelle |
| Versions antérieures au schéma officiel | Historique uniquement |

## Données sensibles

Ne publiez jamais de mots de passe, clés API, jetons OIDC, cookies, secrets d'agents, clés privées, données nominatives réelles, données Active Directory de production ou journaux sensibles.

Une correction de sécurité peut être publiée sous la forme d'une version corrective telle que `v0.1.1`.
